# Web extraction adapter

`adapters/web_extraction.py` implements bounded extraction of one HTML response for F.R.I.D.A.Y. research. It is offline by default and returns provenance fields for citation review: `injected-transport` by default and `scrapling-static` for the optional static Fetcher path. That Scrapling transport uses `Fetcher.get` only after a trusted host egress capability grants the exact URL and limits. Synthetic tests cover CSS fields, tables, markdown, challenge/empty pages, access denial, rate limits, redirects, node/depth/byte bounds, untrusted prompt-like page text, and a fake Scrapling Fetcher.

The host transport is a security boundary. It must bind outbound DNS results to approved public IPs and enforce exact host policy on requests and redirects. For Scrapling, it must also cap bytes during download: the adapter checks `page.body` size only after `Fetcher.get` returns. The adapter's source/final URL checks cannot inspect hidden secondary requests or stop a malicious transport. No live browser/Crawl4AI/Playwright/StealthyFetcher or Firecrawl call is wired in this release. See the [skill extraction reference](../skills/research/friday-web-research/references/EXTRACTION.md) for supported selectors and upstream API/version notes.
