# Security reports

Friday Skills is a public beta. Please use **Security → Report a vulnerability** in this GitHub repository so the details remain private at first. Do not post credentials, personal data or exploitable details in a public issue.

Include the affected revision, prerequisites, observed impact and a minimal reproduction with synthetic data. Use public issues for ordinary bugs and feature requests.

This package contains skill procedures and optional adapters. A packaged skill is not proof of a configured or verified live provider connection.
