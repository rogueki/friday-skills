# Friday mit Hermes-Standardfähigkeiten

Diese Übergaben beziehen sich auf die lokal gelesenen gebündelten `SKILL.md` von Hermes Agent v0.22.2 (2026-09-24). Ein sichtbarer Skill-Eintrag beweist nur Discovery. Vor einer Aufgabe muss Friday Werkzeug, Abhängigkeiten, Anmeldung, erlaubten Pfad und Ergebnis im aktiven Hermes-Prozess prüfen. `registry/integration_setup.json` bleibt ein statischer Einrichtungskatalog mit `live_status: unknown`.

| Vorhaben | Friday-Aufgabe und Hermes-Übergabe | Einrichtung und Grenze |
| --- | --- | --- |
| Präsentation | `friday-presentation-director` erstellt Storyline und Quellenplan; Hermes `powerpoint` erzeugt, liest oder bearbeitet PPTX über seine gebündelten `pptx_create.py`, `pptx_read.py`, `pptx_edit.py` oder `pptx_from_template.py`; `friday-presentation-qa` prüft Ergebnis. | Python `python-pptx` ist erforderlich. `pptx_render.py` braucht für Bildausgabe optional LibreOffice und Poppler. Vor dem Aufruf Hermes-Skill und konkrete Skripte im Laufzeitkontext lesen und Pfade absolut auflösen. PDF/PNG ersetzt keine Sichtprüfung oder native PowerPoint-Animationsprüfung. |
| Desktop-Oberfläche | Falls eine Quelle nur in einer autorisierten App zugänglich ist, kann Hermes `computer_use` zunächst mit `action="capture", mode="som", app=<App>` erfassen, anschließend einen aktuellen `element`-Index anklicken und mit `capture_after=True` erneut prüfen. Friday verarbeitet nur tatsächlich gelesene Daten weiter. | Hermes-Tool und lokaler Desktop-Treiber müssen im aktiven Prozess funktionieren. Ein installiertes SKILL.md oder ein Screenshot allein beweist weder freigegebene Dateipfade noch einen erfolgreichen Klick. Nach jeder UI-Änderung neue Elementindizes verwenden. |
| Obsidian | Hermes `obsidian` löst `OBSIDIAN_VAULT_PATH` oder den dokumentierten lokalen Fallback auf und liest/sucht/bearbeitet Markdown mit Dateitools. `friday-knowledge-base-curator` fügt Quellen-, Versions-, Review- und Dublettenprüfung hinzu. | Autorisierten absoluten Vault-Pfad und konkrete Dateirechte setzen; kein Obsidian-Cloud-Konto für lokale Dateien nötig. Friday bietet keinen allgemeinen KB-Merge-/Indexadapter. |
| Coding-CLI | `friday-project-context-builder` erstellt einen begrenzten, quellenbelegten Projektbrief. Danach kann Hermes je nach expliziter Nutzerwahl und verfügbarer CLI seinen gebündelten `opencode`, `codex` oder `claude-code` Skill über `terminal`/`process` nutzen. | CLI-Binary und Version im **Hermes-Laufzeitkontext** prüfen, eigene Provider-Anmeldung sowie Git-/Projektzugriff bestätigen, Aufrufkosten und Freigaben beachten. OpenCode dokumentiert `opencode run`, Codex `codex exec` im Git-Repo, Claude Code `claude -p`. Ein Windows-Shim in WSL beweist keinen erfolgreichen Modellaufruf. Keine Zugangsdaten im Prompt oder Skill speichern. |
| Telefonie | `friday-phone-call-coordinator` erstellt Gesprächsplan, verifiziert Empfänger und Freigabe. | Kein gebündelter Hermes-Dial-Skill und kein Friday-Dial-Adapter in dieser Installation nachgewiesen. Echter Anruf braucht separat Telefonanbieter, eigene Rufnummer, vertrauenswürdigen Dial-Adapter, verifizierte Ziele und aktionsgebundene Freigabe. CardDAV kann Kontakte liefern, schaltet aber keine Telefonie frei. |

## Beobachtung der lokalen Installation

Am 2026-10-16 wurden in `Friday-Ubuntu` Hermes v0.22.2 und die genannten sechs SKILL.md (PowerPoint, Computer Use, Obsidian, OpenCode, Codex, Claude Code) auf dem Dateisystem gesehen. `opencode` und `codex` lösten in dieser WSL-Shell auf Windows-Shims auf; `claude` und `soffice` lösten dort nicht auf. Das ist kein Auth-, Tool- oder Ausführungsnachweis. Telefonie wurde weder als gebündelter Skill noch als Friday-Dial-Adapter gefunden. Die separate laufende Friday-Installation lieferte bei einem autorisierten Katalogabruf 158 sichtbare Skills (105 Friday, 53 Hermes), ohne Katalogfehler; einzelne Skills und externe Anbieter wurden dadurch nicht ausgeführt.

Die jeweilige Hermes-Skilldatei ist der versionsgenaue Vertrag für konkrete Skriptargumente und Toolaktionen. Nach einem Hermes-Update diese Übergaben erneut gegen den installierten Stand prüfen.
